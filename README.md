# Weather

Сервис для вывода метеорологических данных, получив информацию с удаленного сервиса

## Требования

Для запуска приложения вам понадобятся:
* **Java 17** (или выше)
* **Maven**

## Настройка окружения (Переменные среды)

Приложение использует API геолокации и API погоды и требует наличия секретного ключа. Перед запуском необходимо получить API ключи настроить конфигурационный файл.

API ключ сервиса погода получаем тут https://yandex.ru/pogoda/b2b/console/home

API ключ геодекодера получаем тут https://yandex.ru/maps-api/products/geocoder-api

1. В корневой директории проекта создайте файл с именем `.env` из `env.example`:
   ```bash
   cp env.example .env
   ```
2. Откройте созданный файл и добавьте в него следующую переменную, указав ваш личный токен:
   ```env
   GEO_API_KEY=ключ_api
   WEATHER_API_KEY=ключ_api
   ```
## Запуск приложения

Вы можете запустить проект через вашу IDE (IntelliJ IDEA, Eclipse) либо с помощью командной строки.

### Использование Maven
Сборка проекта:
```bash
mvn clean package
```
Запуск:
```bash
mvn exec:java -Dexec.mainClass="mephi.weather.Main"
```
